Панель администратора

Управление сотрудниками, ролями и функционалом каждого пользователя

Новый сотрудник

Буквы (в т.ч. кириллица), цифры, «_» и «-». Без пробелов — этот логин сотрудник вводит при входе.

Функции пользователя

Смена логина переносит задачи, отчёты и карточку сотрудника. Учётная запись создаётся заново — введите пароль, по которому сотрудник будет входить.

Пресеты ролей

Функции, включённые/выключенные по умолчанию для каждой роли. Админ может менять их для конкретного пользователя.
