# Разделение «Задачи» и «Отчёты» + фильтр по сотрудникам

Дата: 2026-09-09

## Цель

Переработать доску Канбан так, чтобы задачи и отчёты отображались на странице раздельно и переключались кнопками «Задачи | Отчёты». Кнопки переключателя размещаются между шапкой с кружочком статистики и доской (справа). Каждый пользователь видит только свои задачи и отчёты, администратор — все. Добавляется фильтр по сотрудникам (только для администратора), позволяющий просматривать задачи и отчёты конкретного сотрудника.

## Текущее состояние

- Одна доска с тремя колонками: «Срочные» (urgent), «В работе» (in_progress), «Отчёты» (reports).
- `renderBoard()` рендерит колонки `urgent` и `in_progress` для задач, затем `renderReports()` рендерит список отчётов в третью колонку.
- Видимость уже частично реализована:
  - `getTasksForUser()` — админ видит всё, сотрудник — `createdBy === login || assignedTo === login`.
  - `isMyReport()` — админ видит всё, сотрудник — `createdBy === login || assignedTo === login`.
- Кольцо статистики в шапке (`statsRing`) обновляется через `DeadlineHelpers.statsSummary(tasks, reports, login, isAdmin)`.
- Привязка drag & drop только к `list_urgent` и `list_in_progress`.
- Мобильная нижняя панель (`mobile-bar`) фиксирована внизу, тулбар на мобильных скрыт.

## Новое поведение

### Вкладки «Задачи» и «Отчёты»

- В панели инструментов (между шапкой с кольцом статистики и доской), справа, добавляется переключатель из двух кнопок: **Задачи** и **Отчёты**.
- Активная вкладка визуально выделяется (стиль аналогичен `.archive-tab.active` / сегмент-контролу).
- Вкладка «Задачи»: доска с двумя колонками «Срочные» и «В работе» (Канбан, drag & drop сохраняется).
- Вкладка «Отчёты»: один список активных отчётов (как сейчас `renderReports`), отсортированный по сроку `sortByDueDate`.
- При переключении вкладки скрывается/показывается соответствующая область; количество в переключателе не меняется, статистика обновляется.
- На мобильных (≤768px) переключатель отображается над доской в верхней части, т.к. тулбар скрыт.

### Фильтр по сотрудникам (только для администратора)

- Рядом с переключателем «Задачи | Отчёты» выпадающий список сотрудников: первая опция «Все сотрудники», далее все пользователи (по `formatUserName`, без admin-скрытия, сортировка по имени/логину).
- Для сотрудников фильтр скрыт (визуально и по DOM).
- При выборе сотрудника:
  - В «Задачах» показываются только задачи, у которых `createdBy === login || assignedTo === login` выбранного сотрудника.
  - В «Отчётах» — аналогично.
  - Опция «Все сотрудники» (значение `''`) возвращает полный набор по роли (админ — всё).
- Фильтр применяется в `getTasksForUser()` / `isMyReport()` через глобальное состояние `selectedEmployee`.

### Кольцо статистики

- `updateStatsRing()` учитывает активный фильтр: если выбран сотрудник (админ), считает по его задачам+отчётам; иначе — по доступным текущему пользователю задачам+отчётам (как сейчас).

### Архив

- Поведение не меняется: вкладки «Задачи/Отчёты» и видимость по ролям сохраняются. Фильтр по сотруднику на архив не распространяется (остаётся общий список по роли).

### Роли и видимость

- Сотрудник: видит только свои задачи и отчёты (`createdBy` или `assignedTo`), фильтр по сотрудникам не видит.
- Администратор: видит все задачи и отчёты, фильтр по сотрудникам доступен.

## Переменные состояния

- `activeView` — `'tasks' | 'reports'`, по умолчанию `'tasks'`.
- `selectedEmployee` — строка логина или `''` (все), по умолчанию `''`.

## Функции

- `switchView(view)` — переключает вкладку, обновляет активные классы кнопок, показывает/скрывает области, вызывает `renderBoard()`.
- `populateEmployeeFilter()` — заполняет `<select>` фильтра сотрудниками для админа.
- `getTasksForUser()` — расширяется: если `selectedEmployee` задан (админ), фильтровать по выбранному сотруднику; иначе текущее поведение.
- `isMyReport()` — расширяется аналогично.
- `updateStatsRing()` — расширяется учётом `selectedEmployee`.

## Разметка (index.html)

- В `.toolbar`: добавить `.view-toggle-group` с двумя кнопками `#viewTasksBtn` («Задачи») и `#viewReportsBtn` («Отчёты»), а также `#employeeFilter` (select) для админа.
- Доску обернуть так, чтобы можно было показывать/скрывать задачи (`#tasksView`), а список отчётов (`#reportsView`) вынести в отдельную область под тулбаром.
- Убрать третью колонку из доски Канбан; колонка отчётов больше не часть `#board`.
- Для мобильных: элементы переключателя/фильтра дублируются или переносятся стилями в верхнюю зону (не в нижнюю панель).

## Стили (style.css)

- `.employee-filter` — оформление как у `#archiveSearch` (тёмный select).
- `.reports-view` — контейнер одного списка отчётов.
- Медиазапрос ≤768px: выравнивание переключателя/фильтра над доской.
