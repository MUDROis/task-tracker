# Дизайн: удаление сотрудника

Дата: 2026-08-09
Статус: утверждён

## Проблема

В списке пользователей есть кнопка «Изменить», но нет возможности удалить сотрудника.

## Решение

1. **Кнопка «Удалить»** в строке пользователя в `renderUsersList` (модал списка пользователей доступен только admin), рядом с «Изменить». Стиль — как у кнопки «Изменить» (`.btn outline`), надпись «Удалить».

2. **Защита от опасных удалений**:
   - нельзя удалить учётку `admin` — подтверждение `confirm` с сообщением «Удалить сотрудника X?»;
   - нельзя удалить самого себя (текущего администратора): `if (login === currentUser.login) { alert('Вы не можете удалить самого себя'); return; }`.

3. **Действие удаления**:
   - `removeUser(login)` — удаление записи пользователя из Realtime Database;
   - во всех задачах, где `assignedTo === login`: `assignedTo = ''` и `saveTask` (исполнитель очищается);
   - во всех отчётах, где `assignedTo === login`: `assignedTo = ''` и `saveReport` (исполнитель очищается);
   - `createdBy` остаётся прежним — задачи и отчёты, созданные сотрудником, сохраняются как данные команды;
   - `renderUsersList()` — обновление списка.

4. **Побочные эффекты**: удалённый пользователь автоматически исчезает из списка исполнителей (`populateSelect`, `showDelegateModal` работают по массиву `users`), формат имени через `formatUserName` фолбэчится на логин.

## Дополнение по итогам финального ревью (утверждено пользователем)

- **Блокировка входа удалённых**: `removeUser` удаляет только запись из БД; Firebase Auth-аккаунт остаётся. Автосоздание записи (`onAuthStateChanged` и обработчик формы входа) теперь выполняется только для `login === 'admin'`. Не-admin без записи в БД автоматически выходит из системы, на странице входа показывается сообщение «Ваш аккаунт удалён администратором». Единый источник истины — `auth.onAuthStateChanged`; форма входа пользователей не провижинит.
- **Кнопка «Удалить»** не отображается для учётной записи `admin` и текущего пользователя (защита в `deleteUser` сохранена как defence-in-depth).
- **Обновление списка**: `deleteUser` фильтрует локальный массив `users` и вызывает `renderUsersList()` (без повторного запроса к БД — живой `on('value')`-слушатель обновляет доску/select).

## Проверка

- `node --check app.js`.
- Ручная проверка в `index.html`: admin видит кнопку «Удалить» у сотрудников; удаление очищает исполнителя в его задачах/отчётах; нельзя удалить `admin` и самого себя; список обновляется; удалённый сотрудник при входе получает сообщение «Ваш аккаунт удалён администратором» и не попадает в систему.
