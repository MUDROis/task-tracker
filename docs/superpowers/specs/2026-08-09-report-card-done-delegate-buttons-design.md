# Дизайн: кнопки «Выполнить» и «Делегировать» в карточке отчёта

Дата: 2026-08-09
Статус: утверждён

## Проблема

В карточке отчёта в отличие от карточки задачи нет кнопок «Выполнить» и «Делегировать». Сейчас в первом ряду кнопок только «В архив», во втором — «Удалить» (admin), «Настройки», «Открыть».

## Решение

1. **Карточка отчёта** (`createReportCard`):
   - Кнопка «В архив» переименовывается в «Выполнить» с той же логикой: `changeReportStatus(report.id, 'done')` (отчёт уходит в архив).
   - Добавляется кнопка «Делегировать» с условием видимости как у задач: `report.status !== 'done'` и (`currentUser.role === 'admin'` или `currentUser.login === report.createdBy`).
   - Добавляется стрелка-индикатор делегирования в углу карточки при `report.delegated`, идентично карточке задачи (`task-delegate-arrow`, `arrow-received`/`arrow-delegated`, символы ↙/↗).

2. **Делегирование**: функция `showDelegateModal` обобщается до `showDelegateModal(item, saveFn, kind, x, y)`:
   - `item` — задача или отчёт;
   - `saveFn` — `saveTask` или `saveReport`;
   - `kind` — строка «задачу» / «отчёт» для заголовка окна;
   - при подтверждении: `assignedTo`, `delegated: true`, `delegatedBy` (`'admin'` для руководителя, иначе `'employee'`), `updatedAt`, сохранение через `saveFn`, `sendEmailNotification`.
   - Вызов из карточки задачи: `showDelegateModal(task, saveTask, 'задачу', x, y)`.
   - Вызов из карточки отчёта: `showDelegateModal(report, saveReport, 'отчёт', x, y)`.

3. **Детали отчёта** (`showReportDetails`): добавляется строка «Делегировано: Руководителем / Сотрудником» при `report.delegated` — как в деталях задачи.

4. **Архив отчётов** (`createArchiveReportRow`): без изменений.

## Модель данных отчёта

Отчёт получает поля `delegated: boolean` и `delegatedBy: 'admin' | 'employee'` (по аналогии с задачами). Для существующих отчётов поля отсутствуют — код обрабатывает это как `undefined` (ложно).

## Проверка

- `node --check app.js`.
- Ручная проверка в `index.html`: на карточке отчёта видны «Выполнить» и «Делегировать»; делегирование меняет исполнителя, показывает стрелку, шлёт email; «Выполнить» архивирует; у не-создателя и не-admin кнопка «Делегировать» скрыта.
