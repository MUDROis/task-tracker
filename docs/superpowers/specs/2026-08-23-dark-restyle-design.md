# Тёмный рестайл в стиле референса «treker»

- Дата: 2026-08-23
- Статус: утверждено пользователем (подход A; подложка модалок остаётся прозрачной)

## Цель

Перевести текущий Kanban-трекер на визуальный стиль референса
(`Downloads/treker-main/index.html`): тёмная тема, оранжевый акцент,
шрифты Golos Text + Unbounded, кружок статистики в шапке, акцентные кнопки,
карточки задач в стиле референса. **Весь функционал сохраняется без изменений.**

## Что меняется

### 1. `style.css` — полная переработка (главное)

Все существующие селекторы и имена классов сохраняются. Меняются только значения:

- Дизайн-токены референса в `:root`: `--bg0:#0a0d13`, `--bg1:#0f131c`,
  `--surface:#141a26`, `--surface2:#1a2231`, `--line`, `--text`, `--muted`,
  `--faint`, `--accent:#ffb454`, `--accent-hi`, `--accent-ink`, `--danger`.
- Фон: сетка 36px с радиальной маской + два размытых орба (fixed, за контентом).
- Кнопки: `.btn.primary` — оранжевая со свечением и подъёмом при hover;
  `.btn.secondary`/`.outline` — тёмные поверхности; `.btn-logout-inline` — ghost.
- Колонки доски: тёмные поверхности, пилюли-счётчики.
- Карточки `.task-card`: тёмная поверхность, радиус 14px, левая полоска дедлайна
  (`strip-*`) — те же смыслы, цвета чуть ярче для тёмного фона; hover-подъём;
  кнопки действий — тонированные пилюли; стрелки делегирования — акцент/danger.
- Модалки: тёмный контент; **подложка `.modal` остаётся прозрачной** (требование
  пользователя), добавляется только лёгкое затемнение фона контента не делается.
- Архив, тосты, мобильная панель, скроллбар, selection, focus-visible — на тех же
  токенах.

### 2. `index.html` — точечные вставки

- Шрифты @fontsource (jsdelivr): Golos Text 400/500/600, Unbounded 600/800.
- `<meta name="color-scheme" content="dark">`.
- В `.header-right` перед кнопкой выхода — кольцо прогресса
  (conic-gradient по `--p`, ядро с процентом), как `.ring` референса.
- Два div-орба фона в начале `body`.

### 3. Статистика кружка

Метрика: **% выполненных** = выполненные / все доступные пользователю задачи+отчёты.

- Видимость: админ — все; сотрудник — где `createdBy` или `assignedTo` == его логин
  (те же правила, что у `getTasksForUser()` и `isMyReport()`).
- Выполнено = `status === 'done'` (задачи и отчёты).
- Чистая функция `DeadlineHelpers.statsSummary(tasks, reports, login, isAdmin)`
  → `{total, done, pct}` в `js/helpers.js`; TDD через `tests/stats.test.js`
  (node:test, по образцу `deadline.test.js`).
- Обновление кольца — в конце `renderBoard()` (единственная точка перерисовки).

### 4. Мелкие правки светлых артефактов

- `app.js`: inline `color:#334155` в детальных модалках → `var(--muted)`;
  «Нет задач/отчётов» (`#94a3b8`) остаются — читаемы на тёмном.
- `service-worker.js`: `CACHE_NAME` v5 → v6 (инвалидация кэша стилей).
- `manifest.json`: `background_color`/`theme_color` → `#0a0d13`.

## Инварианты

- Ни один ID, класс-хук (`data-action`), обработчик, drag&drop, Firebase-код,
  Excel-импорт/экспорт, уведомления — не изменяются.
- JS-изменения только аддитивные: хелпер статистики + вызов обновления кольца
  + замена двух inline-цветов.

## Проверка

1. `node --check app.js js/helpers.js service-worker.js`.
2. `node --test tests/` — все тесты зелёные, включая новый `stats.test.js`.
3. Ручная визуальная проверка страниц: вход, доска, модалки, архив.
