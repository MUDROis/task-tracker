# Спека: Карточка задачи — жесты, даты, цветовая шкала полосы

Дата: 2026-08-25
Область: карточки задач и отчётов (доска Kanban), мобильная и десктопная версии.

## Цели

1. Скрыть органы управления в карточке по умолчанию; показать по одиночному тапу (мобильные) / наведению курсора (десктоп); двойной тап открывает полную модалку.
2. Убрать из карточки дату создания; оставить только срок в формате `ДД.ММ.ГГГГ ЧЧ:ММ` с иконкой календарика.
3. Динамический цвет левой полосы по близости срока (календарные дни).

## 1. Поведение карточки: тап / двойной тап / hover

### Мобильные устройства (`@media (hover: none)`)

- Обе строки кнопок (`task-actions-row1`, `task-actions-row2`) скрыты по умолчанию (`display:none`).
- **Одиночный тап** по карточке → класс `.controls-open` на `.task-card` → строки раскрываются внутри карточки. Повторный тап — сворачиваются.
- Открытие одной карточки сворачивает ранее раскрытую (единственная раскрытая карточка за раз).
- **Двойной тап** (два `click` с интервалом <300 мс) → таймер одиночного тапа отменяется, открывается модалка:
  - автор/админ → окно редактирования (`openTaskModal` / `openReportModal`);
  - остальные → просмотр деталей (`showTaskDetails` / `showReportDetails`). Алерты «Вы не можете редактировать» убираются.

### Десктоп (`hover:hover`)

- Кнопки обеих строк скрыты по умолчанию, появляются при наведении курсора на карточку (`:hover`), как сейчас для row2, распространено на row1.
- **Двойной клик** (`dblclick`) открывает ту же логику модалки по правам. Одиночный клик на десктопе ничего не переключает.
- Текущие правила `:focus-within`, `@media (hover:none)` для row2 заменяются новой схемой.

### Общее

- Детектор тапов — функция в `app.js`, подключается к карточкам задач и отчётов только при `matchMedia('(hover: none)').matches`.
- Детектор слушает нативные `click`: после drag&drop браузер не генерирует `click`, поэтому перетаскивание не togg'лит карточку.
- Тапы по кнопкам внутри карточки игнорируются детектором (`stopPropagation()` уже стоит на кнопках).
- `touch-action: manipulation` на `.task-card` — отключение двойного тапа-зума.
- Кнопка «Открыть» (ⓘ) остаётся альтернативным путём к деталям.
- Логика выбора модалки по правам — общая функция для task/report и для dblclick/детектора.

## 2. Даты в карточке

- Спан «Дата создания» (`📅 …`) удаляется из `createTaskCard`.
- Срок выполнения: единственная дата, формат `ДД.ММ.ГГГГ ЧЧ:ММ` через существующую `formatDateTime()`.
- Иконка ⏳ заменяется на Font Awesome календарик `fa-regular fa-calendar` (в задачах и отчётах).
- Остальные элементы мета-строки (исполнитель, № отчёта) без изменений. Без срока дата не выводится (как сейчас).

## 3. Цветовая шкала полосы срока

Отсчёт — календарные дни (`calendarDaysUntil`, от начала дня до начала дня).

| daysLeft | Класс | Цвет | Hex |
|---|---|---|---|
| нет/неверный срок | `strip-none` | серый | `#64748b` |
| > 5 | `strip-ok` | зелёный | `#22c55e` |
| 4–5 | `strip-warn` | салатовый | `#a3e635` |
| 3 | `strip-orange` | оранжевый | `#f97316` |
| 1–2 | `strip-scarlet` | алый | `#ef4444` |

Изменения против текущего кода:

- День срока (0): был `strip-overdue` → станет `strip-red`.
- «За 1 день»: был `strip-red` (#ef4444) → станет алый `strip-scarlet`.
- Класс `strip-coral` (#fb7185) удаляется, вместо него `strip-scarlet`.
- Просрочка темнее: `#be123c` → `#881337`.
- CSS обновляется для `.task-card.strip-*` и `.archive-row.strip-*`; архив и выполненные карточки наследуют шкалу через `doneStripClass` без правок логики.

## Edge cases

- Задача без `dueDate` или с невалидной датой → `strip-none`, дата не показывается, тапы работают.
- Быстрый третий клик после двойного — не открывает вторую модалку (таймер сбрасывается, повторное открытие модалки идемпотентно).
- Раскрытая карточка при перерендере доски (после любого изменения) снова скрыта — приемлемо.
- Drag&drop: `dragstart` гасит последующий `click` — toggle не срабатывает.
- Клавиатурная навигация сохраняет доступ к действиям через фокусируемые кнопки после раскрытия; отдельной клавиатурной логики раскрытия не вводим (YAGNI).
